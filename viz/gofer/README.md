# Visualization options

Generally: for the basemap, you can tweak zoom levels (default 12). This allows you to have a higher/lower resolution for the basemap, at the cost of compute.

1. `active_fire`: plots the active fire over time. Generates a GIF.
2. `fire_perimeter`: plots the fire perimeters over time, on one image. Generates a PNG.
3. `ortho`: Plots the orthorectification used to visually validate this part of the pipeline
